# Plinko - A project management tool

> Like a plinko game; given the tasks at the top the timelines should fall into place

Plinko is (or will be) a project managment tool, built for my needs. It prioritises flexible and adaptible scheduling using workload estimation and dependancies. It features (or will feature) a planning page and a day to day usage page for each project member.

## Features

- [x] Simple UI using skia
- [ ] Tasks
    - [ ] Storage
    - [ ] Creation
    - [ ] Editing
- [ ] Folders and hierarchy
- [ ] Dependancies
- [ ] Workloads
    - [ ] Per task
    - [ ] Cumulative per folder
