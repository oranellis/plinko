I would like to change the UI flow for the application now. I would like the app to be focused around a homepage that the user will land on when opening the website. This homepage should display information and buttons that a user might use to glance at what tasks they need to do today. It should have buttons that open the different views, such as calendar editing, plan overviews, and settings pages.

Here is a list of concrete changes I would like to make:

The username logout button at the top right should be replaced with a person circle icon indicating the user options. This button should bring up a small context menu with logout and preferences options, as well as the user's name. I want a similar menu to what's seen on most modern web apps here.

Add a user preferences screen which has the calendar format, Password changing, display name changing, and any other user-specific options you can think of. Make this Page accessible from the aforementioned preferences option in the top right.

Get rid of the My Work page. I want to replace this with a better display. Change the naming of this page back to Allocations, From Version 1. Look at the' version 1 code for how the allocations are shown. It should show all the tasks across all plans, sorted vertically in order of start date. Hovering tasks should show additional information, and clicking tasks should edit them on this page as well.

The next thing to overhaul is the calendar and availability entry screen with the calendar rules and stuff. I would like availability, entry, and hours to be on a new floating window which shows a vertically scrolling calendar with the calendar display indicating the availability on that day shown by a day background effect. I would then like a small indicator on days that have rules applied. And clicking on a day should allow you to enter a new rule with a new Pane to the right of the calendar. This pane should have a new rule entry section and an existing rules entry section below which can be a scrollable list showing the details. You should also be able to delete rules from this pop-up that appears when you click on the day. Maybe actually for good user flow of this, the top section that shows the new rule or edit rule details is blank until you click a new rule button. It then creates a rule in the list below and selects it for editing.

There are several "save", "delete", "close") bottom sections on floating and other windows. I would like these across the app to generally be fixed at the bottom, and not part of a scrollable window so they can be clicked from any scroll position.

Remove the plan selector from the top of the plan (it's name) and add a back button to the left of the Today button on the plan viewing screen. To change plans, I'd like users to go back to the plan list and then select a different plan.

Add a favourites indicator (star that's gold when selected) at the top right of the plan cards on the plan screen. Add a favourites section at the top of the plans screen when at least one plan is favourited.

Leave this new homepage I've described a bit sparse just now. There should be a top section for Upcoming Work, then the next section for Quick Accessing Plans.

The calendar availability selector I described earlier makes a full page version that still just has the calendar in the center that can be accessed for the user wanting to change their overall availability. The floating window version of this page should also be used for stuff like task affinities as well, though.

On plan views for buffers, rather than the dotted outline boxes, can you have a horizontal dotted line with two vertical dotted endbars, and then a number then letter d to indicate the number of days that the buffer is? Also, have buffers show their current duration and additionally their assigned duration in brackets. Can you also improve the way buffers are displayed when they have completely vanished? I want them to take up at least one day of width, even if they are zero days. Otherwise, they are difficult to click on and look bad.
